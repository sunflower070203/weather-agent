## 可直接使用的作品简介

户外天气决策 Agent 面向骑行、徒步和露营场景。它通过多轮对话补齐地点、时间和时长，调用真实逐小时天气数据，以确定性规则识别降雨、大风、高温和低温风险，再给出可执行的主方案与备选方案。用户修改计划后，系统会保留有效状态并重新查询、重新评估；遇到地点歧义、预报越界或工具失败时，会要求确认或安全停止，不编造结论。
