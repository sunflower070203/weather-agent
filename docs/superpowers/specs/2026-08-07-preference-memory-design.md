# 会话内偏好记忆设计

## 第一性原则取舍

用户可能表达“我比较怕热”“想稳妥一点”。这类信息应影响建议口径，但不能影响风险阈值：README 成功标准要求“相同天气指标应得到稳定的风险等级”，阈值变化会让评测和解释失去可复现性。

因此本阶段只做会话内偏好记忆：

- 提取：模型只在用户表达风险态度时更新 `risk_preference`；
- 归一化：中文与英文别名统一为 `conservative`、`moderate`、`adventurous`，未知值安全拒绝；
- 消费：推荐语按偏好追加一行提示，风险等级与知识建议保持确定性。

不做跨会话长期记忆：项目没有账号和数据库，状态随会话结束而消失。

## 行为

| `risk_preference` | 推荐语追加内容 |
|---|---|
| `conservative` | 偏好保守，建议优先采用更稳妥的备选方案 |
| `adventurous` | 接受较高风险，但仍以数据结果为准 |
| `moderate`（默认） | 不追加 |

## 提取提示

系统提示新增一行：仅在用户表达风险态度时提取 `risk_preference`，否则省略该字段。

## 评测

- 单测：未知偏好被领域校验拒绝；中文别名归一化；模型返回未知偏好被提取器拒绝；
- Agent 测试：保守偏好改变文案但风险等级不变；默认偏好不出现偏好行；
- 评测场景 `agent.023`：降雨中风险下出现“保守”提示，风险等级仍为 `precipitation medium`。

## 局限

偏好识别依赖模型对口语的提取，确定性校验只保证取值合法；偏好是会话级，不跨会话保留。
