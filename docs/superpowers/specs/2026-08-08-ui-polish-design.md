# UI 精修设计（专家身份可视化）

## 目标

在不动 Agent 逻辑的前提下，把"三位专家分工"变成打开页面和阅读回复时第一眼可见的形态，并整体打磨现有"户外编辑台"风格的细节。用户已确认采用方案 A（精修现有方向）。

## 改动范围

- 头部新增专家徽章行：`🌦️ 气象顾问 · 🦺 户外安全顾问 · 🎒 装备与补给顾问`；
- 聊天回复专家段之间加细分隔线（`---`），文案与断言不变；
- 右侧面板层次：计划摘要信号橙左边框卡片化；能力/专家列表加图标前缀并收紧行距；
- 排版与氛围：中文字体栈、页面淡入动效、按钮 hover、面板圆角与滚动条细节；
- 保留双栏布局、移动端适配、版本页脚与数据来源说明。

## 明确不做

不换配色体系、不引入外部字体或依赖、不改消息文案与状态机、不做暗色主题。

## 验收

`python -m unittest discover -s tests` 与 `python -m evals.run` 全绿；部署后线上肉眼验收头部徽章、三段分隔与面板层次。
