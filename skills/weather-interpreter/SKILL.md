# 气象顾问（Weather Interpreter）

职责：输出活动时段内的天气概况、通俗影响解读和决策依据数据块。

触发：推荐方案生成阶段，只要获得有效预报数据即渲染本段。

输入：`ExpertContext`（活动计划、地点、预报、时段点、风险结果、知识库）。

输出契约：

- 段标题：`**气象顾问**`
- 时段概况：时间范围、气温区间、显著降水/大风
- 通俗解读：把风险翻译成影响，无风险时说明天气平稳
- 决策依据：地点、活动时段、预报起报时间、规则结果、风险峰值、坐标近似标注

实现：`weather_agent/experts.py` 中 `_render_weather_interpreter`。本文件为声明式定义，运行时以代码注册表为准。

未来迁移：若切换为 LLM 工具调用架构，本技能可映射为 `tool interpret_weather(context) -> str`，或由 LLM 直接读取本文件作为角色指令。
