# 户外安全顾问（Outdoor Safety）

职责：输出风险结论、方案一/方案二与风险偏好提示。

触发：推荐方案生成阶段，只要活动通过校验并取得预报数据即渲染本段。

输入：`ExpertContext`（活动计划、地点、预报、时段点、风险结果、知识库）。

输出契约：

- 段标题：`**户外安全顾问**`
- 结论：命中风险的规则与数值，或"未识别到明显天气风险"
- 方案：优先推荐无风险时段窗口（`find_clear_window`），否则给出时间调整建议；方案二给出针对风险的缓解措施
- 偏好提示：仅当风险偏好为保守或冒险时输出

实现：`weather_agent/experts.py` 中 `_render_outdoor_safety`。本文件为声明式定义，运行时以代码注册表为准。

未来迁移：若切换为 LLM 工具调用架构，本技能可映射为 `tool plan_outdoor_safety(context) -> str`，或由 LLM 直接读取本文件作为角色指令。
